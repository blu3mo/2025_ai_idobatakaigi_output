# 背景
東京都の教育分野では、急速なデジタル化の進展に伴い、AI技術を活用した教育改革が急務となっています。しかし、教師の負担増大、教育格差の拡大、そしてAIリテラシーの普及の遅れなど、課題が山積しています。特に、AI教育に対する準備不足や、教員のスキルギャップが大きな障害となり、教育現場での効果的なAI活用を進めるためには、支援体制の整備と学習環境の改善が不可欠です。

さらに、AGI（汎用人工知能）の急速な発展により、従来の教育モデルが前提としてきた「知識の階層的習得」という概念自体が問い直されています。今後の社会では、自分自身の知識や理解を超えた分野であっても、AIと協働することで問題解決できる能力が重要となります。東京都の教育は、この新たな時代に適応するための根本的な変革が必要です。

本提言の作成にあたり、AIチャット、掲示板、X、YouTube等を通じて有識者の意見を収集し、教育格差の是正の必要性や、AI活用の有効性、導入にあたってのハードル、プライバシーと監視のバランス、AI導入の優先順位などの論点を検討しました。既に海外ではAIの教育現場に対する影響の研究があり、大きなポテンシャルがあることがわかっています。

# AGI時代の教育目標再定義

従来の教育モデルは、基礎知識の習得から始まり、応用、そして実践へと階層的に進む構造でした。しかし、高度なAIが普及する社会では、この前提が根本から変わります。私たちが提案する新たな教育目標は以下の通りです：

## 1. 自分の理解を超えた領域でもAIを介して問題解決できる自己効力感の育成

小中学生が微積分の詳細を理解していなくても、AIを通じて微積分を活用した問題を解決できるようになる世界を想像してください。ここで重要なのは、「わからないことを理解するために努力する」だけでなく、「わからないままでも問題を解決する方法を見つける」という新しい学習観です。

## 2. 自分の目標にAIをalignさせる能力の開発

AIツールを単なる「便利な道具」ではなく、自分の意図や目標に沿って働かせる能力が重要になります。これは表面的なプロンプト技術ではなく、AIと人間の協働において人間が主導権を持ち続けるための根本的なスキルです。

## 3. 知識の階層を超えた学習モデルの構築

従来の「基礎から応用へ」という順序立った学習モデルから、AIを活用して複雑な問題に直接取り組み、必要に応じて基礎に戻るという柔軟な学習モデルへの転換が必要です。

# 提案要旨

これらの新たな教育目標を達成するため、以下の3つの施策を提案します：

1. **拡張知性体験プログラム**: 東京都の児童・生徒にChatGPT等のLLMを配布し、自分の理解を超えた分野でもAIを活用して問題解決する経験を提供します。

2. **次世代AIリテラシー教育**: 従来の「AIの使い方」ではなく、AIと協働して自分の目標を達成する能力を育成する教育プログラムを実施します。

3. **教師のAIエンパワーメント**: 教師自身がAIを活用して教育内容や方法を拡張し、新しい教育モデルを実践するための支援を行います。

これらの施策により、東京都の子どもたちはAGI時代に必要な新たな能力を獲得し、未来社会の複雑な課題に対応できる人材へと成長します。

# 施策案

## 施策A：拡張知性体験プログラム - 自己の理解を超えたAI活用体験の提供

### 施策の詳細
ChatGPT等の既成のLLM（大規模言語モデル）を全児童・生徒に配布し、自分自身の知識や理解を超えた分野でも問題解決ができる経験を提供します。重要なのは単なるツールの配布ではなく、「自分だけでは理解できなくてもAIと協働することで達成できる」という成功体験を積み重ねることです。

OpenAIやAnthropicと東京都として交渉して、教育現場においてどれだけ成果が挙げられたかを大規模にテストさせることをバーターに安くライセンスを仕入れることを目指します。AIを児童・生徒が学習に活用することで、従来の学習法の限界を超え、新しい問題解決アプローチを身につけることが可能になります。

### メリット
- **知識の階層を超えた学習経験の提供**
  - 従来なら高校や大学で学ぶ内容も、AIを通じて小中学生が挑戦できるようになり、学習意欲と自己効力感が向上します
  - **例**: 中学生が量子力学の基本概念をAIに説明してもらいながら、量子コンピューティングの簡単なプロジェクトに取り組む

- **東京都がAIを与えることで、親が子どもにAIを与えるかどうかの格差を是正**
  - **ナイジェリアのエド州でのAIチューター導入例**: ナイジェリアでは、無料のAIチューターを導入することで、貧困層の生徒も高価な家庭教師に頼らず学習支援を受けることができ、教育格差を是正する効果が確認されています。

- **新しい自己効力感と学習観の醸成**
  - 「わからないことがあっても、AIを活用して問題を解決できる」という新しい自己効力感を育みます
  - これにより、未知の問題に対する恐れや苦手意識が軽減され、挑戦する姿勢が育まれます

- **教員が全生徒に個別対応する負担を軽減**
  - **イギリスの「Aila」プロジェクト**: イギリスでは、教師向けのAIアシスタント「Aila」を開発し、授業準備や教材作成をサポートすることで、教師の負担軽減を図りました。

### 課題とその解決策
- **新しい「わからなさ」への対処方法**
  - AIを使っても解決できない問題が生じた場合の対処法を教え、「わからない」ことを恐れず、様々な方法で解決策を探る姿勢を育てます
  - 将来的には、「答えは教えないが詰まっている箇所の考え方は教える」というKhanmigo的なAIに移行していくことも検討します

- **予算・ライセンス取得に関する課題**
  - 教育現場においてどれだけ成果が挙げられたかを大規模にテストさせることをバーターに安くライセンスを仕入れることを目指します
  - 東京都の規模を活かした交渉力で、教育機関向けの特別ライセンスを獲得します

- **プライバシー保護（学習履歴や誤答履歴など個人情報の取り扱い）**
  - 個人情報を活用しない方針でレギュレーションを定め、データ利用のガイドラインを明確化します
  - 子どもの安全を確保しつつ、学習データの匿名化と保護を徹底します

### 挙げられた意見
> 生徒が誤答した際にヒントや質問例をリアルタイムで提案されるべきです。ハードルになる点は、システム設計と構築や、システムの利用を可能にする制度の準備です。少なくとも、一斉授業だけではなく、自由に操作できる時間が必要です。また、UDL 上は必ずしも最適化されていない方法でのやり取りが行われる可能性があります。大前提としてWebAIM が提唱するアクセスビリティは提供される必要があります。音声による指示とテキスト入力による指示が行えます。([@akinori](https://large-scale-conversation-sandbox.discourse.group/t/topic/78/17?u=eitaro))

> AIへのアクセスを配るにあたって「子供とAIの1対1の密室コミュニケーション」ではなく、教室に副担任やTAのような形で配備することが考えられる。（[@nishio](https://large-scale-conversation-sandbox.discourse.group/t/topic/78/8?u=eitaro)）

## 施策B：次世代AIリテラシー教育 - AIとの協働で目標を達成する能力の育成

### 施策の詳細
小学校高学年から高校までのカリキュラムに、従来型の「AIの使い方」ではなく、「AIと協働して自分の目標を達成する能力」を育む「次世代AIリテラシー教育」を段階的に導入します。ここでの焦点は、AIツールの操作方法ではなく、自分の意図や目標にAIをalignさせ、AIと協働して複雑な問題を解決する能力の開発です。

### メリット
- **AIとの新たな関係性の構築**
  - AIを単なる「道具」ではなく、自分の思考や能力を拡張するパートナーとして位置づける視点を育みます
  - 人間とAIの役割分担を理解し、それぞれの強みを活かした協働方法を学びます

- **AGI時代に不可欠な思考法の習得**
  - AIによって代替される単純作業や知識の暗記ではなく、問題設定能力や創造的思考など、人間にしかできない能力を重点的に育成します
  - **スタンフォード大学の「Tutor CoPilot」実験では、AIアシスタントを活用することで、学生が複雑な問題に直接取り組み、必要に応じて基礎概念を学ぶという新しい学習スタイルが確認されました。**

- **すべての児童・生徒への平等な機会提供**
  - 家庭環境や経済状況に関わらず、全ての子どもたちがAGI時代に必要なスキルを習得できる環境を整えます
  - **ナイジェリアのエド州での生成AIプログラムでは、家庭の経済状況にかかわらず、全ての生徒に対話型英語練習を提供し、特に低所得層の生徒の学力向上が顕著でした。**

### 課題・リスク
- **新たな教育目標に対する理解促進**
  - 従来の「知識習得」中心の教育観から「AIと協働した問題解決能力」への転換に対する理解を広めるため、教師や保護者向けのワークショップを開催します
  - 成功事例を積極的に共有し、新しい教育アプローチの効果を実証します

- **教員のAIリテラシーと新たな教育観の習得**
  - 教員向けに、AIとの協働を前提とした新しい教育方法の研修プログラムを提供します
  - 教員自身がAIと協働して問題解決する経験を積み、その経験を教育に活かせるようサポートします

- **既存の学習指導要領との整合性の確保**
  - 従来の教育目標と新たな教育目標の両立を図るための移行期間を設け、段階的に新しい教育観を導入します
  - 新旧の教育方法が共存する期間の評価方法や目標設定を明確にします

### 挙げられた意見
> AIを全く使ったことがないという生徒がいないように、AIに触れる＋AIリテラシーについて学ぶ時間はあった方がよい。（[@westcoaster](https://large-scale-conversation-sandbox.discourse.group/t/topic/78/11?u=eitaro)）

> 小学校では触れる機会の担保、家庭の監督のもと補助に使う。中学校では活用の実践まで含み、自己責任で補助に使う感じで。（[@yamaokakitaro](https://large-scale-conversation-sandbox.discourse.group/t/topic/78/14?u=eitaro)）


## 施策C：教師のAIエンパワーメント - 新しい教育モデルの実践支援

### 施策の詳細

東京都は、教員がAI時代の新たな教育モデルを実践するためのAIツールの開発を公募を通じて調達します。このツールは単なる業務効率化だけでなく、教師自身が「自分の理解や能力を超えた領域でもAIと協働して教育できる」経験を提供します。具体的には、イギリスの「Aila」型を参考に、カリキュラムに準拠した教材案やレッスンプランを提示する機能、そして教師自身の知識を超えた専門分野の授業実施支援など、新しい教育観に基づく機能を実装します。

## メリット

- **教師自身による「拡張知性」の実践**
  - 教師自身が「AIによる能力拡張」を体験し、その経験を児童・生徒に伝えることで、新しい学習モデルの実践例となります
  - **イギリスのAilaプロジェクト**では、教師がAIを使って自分の専門外の分野にも踏み込んだ授業を行うことで、生徒の興味関心を広げる効果が確認されています

- **新たな教育モデルの実験場の創出**
  - AIを活用した新しい教育方法の実践例を蓄積し、効果的なアプローチを見出すための実験の場となります
  - 従来の「知識伝達型」から「AIと協働した問題解決型」への教育転換を促進します

- **教師の新たな役割の確立**
  - AIの普及により、教師の役割は「知識の伝達者」から「AI時代の学びのファシリテーター」へと変化します
  - これにより、教師は生徒一人ひとりの思考プロセスやAIとの協働方法に注目し、より深い教育的関わりが可能になります
  - **アメリカのスタンフォード大学のTutor CoPilot実験**では、AIアシスタントを活用することで、教師の役割が「知識の伝達」から「思考プロセスのガイド」へと変化し、生徒の深い学びにつながったことが報告されています

### 課題・リスク
- **AIへの過度な依存と教師の専門性の位置づけ**
  - AIはあくまで教師の能力を拡張するツールであり、教師の専門性や人間的な関わりの重要性を再確認する研修を実施します
  - AI時代における教師の新たな専門性（思考プロセスの支援、感情面のサポート、価値観の形成など）を明確化します

- **AIが生成する教材の質と責任の所在**
  - AIが生成した教材の質を評価するためのガイドラインを策定し、最終的な教育内容の責任は教師が持つことを明確にします
  - AIの使用により生じる可能性のある問題への対応方法を整備します

- **システムの導入・定着における抵抗感**
  - 新しい教育モデルへの移行を支援するためのメンター制度を設け、先進的な事例を共有する場を提供します
  - 教師のAI活用を評価する新たな指標を開発し、積極的な取り組みを評価する仕組みを整えます

### 挙げられた意見
> 業務効率化（教員の補助）という点ではITもAIもどんどん使うべき。（[@yamaokakitaro](https://large-scale-conversation-sandbox.discourse.group/t/topic/78/14?u=eitaro))

# 結論：AGI時代の東京都教育への展望

本提言は、単にAIツールを教育現場に導入するという表層的な改革ではなく、AGI時代における教育の根本的な転換を目指すものです。従来の「知識の階層的習得」から「AIと協働した問題解決能力の育成」へと教育目標を再定義し、東京都の子どもたちが未来社会で真に活躍できる力を育みます。

3つの施策を通じて、子どもたちは「自分の理解を超えた領域でもAIと協働して問題解決できる」という新しい自己効力感を獲得し、AIが普及する社会での新たな学習観と問題解決アプローチを身につけることができます。

東京都がこの教育改革を実現することで、日本全体のAI時代における教育モデルの先駆けとなり、未来を創造する人材を育成する教育先進都市としての地位を確立することができるでしょう。
